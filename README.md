# Pirate Alliance 데모

Unity **6000.3.19f1 / URP 17.3.0**. 로비에서 편성하고 던전에 진입해 전투·증강·보스·귀환 보상·영구 강화를 반복하는 데모입니다.

## 포함 콘텐츠

- 플레이 캐릭터: **프로이**. 아스트라이아와 개발 중인 남궁루나는 데모 선택 대상에서 제외합니다.
- 지원 캐릭터: **유니**(Q 액티브), **꼬끼오**(처치 시 회복 아이템 드롭).
- 던전: **리미널 스페이스 G-01**, **게임 테마 G-06**. 각각 일반 전투방 3개와 보스방 1개입니다.
- 로비 편성 담당 요원: 캐릭터·지원 캐릭터 선택과 저장. 현재 완성된 플레이 캐릭터는 프로이 1종이며 캐릭터 선택 시스템은 유지합니다.
- 로비 협회 요원: 던전에서 얻은 마석으로 체력·공격·회피·반격 영구 강화.
- 전투: 3타 콤보, 대시·저스트 회피, 잡아 던지기·화염공, 궁극기, 공통·프로이 전용 증강, 패배·재도전·귀환.

## 실행

1. 저장소를 받은 뒤 `git lfs pull`을 실행합니다. 폰트·모델·텍스처·음원은 실제 LFS 파일이 필요합니다.
2. 실행 전 본인 계정의 **Magica Cloth 2**를 `Assets/MagicaCloth2`로 가져옵니다. 프로이 머리카락·의상 물리에 필요한 유료 패키지 원본은 저장소에 포함하지 않습니다.
3. Unity에서 `Assets/Liminal/Scenes/LiminalRun.unity`를 열고 재생합니다.
4. 로비의 편성 담당 요원에게 E로 말을 걸어 지원 캐릭터를 고르고, 파란 게이트에서 미션을 선택합니다.
5. 전투방을 정리하고 증강을 고른 뒤 다음 방으로 이동합니다. 보스를 처치하고 출구에서 E를 눌러 승리 화면을 연 뒤 로비로 귀환합니다.
6. 협회 요원에게 E로 말을 걸어 마석으로 강화한 뒤 다시 출발합니다.

| 조작 | 기능 |
| --- | --- |
| WASD | 이동 |
| 마우스 좌클릭 | 프로이 3타 콤보 |
| 마우스 우클릭 / K | 가까운 적 잡아 던지기, 없으면 화염공 |
| Space | 대시·회피 |
| R | 궁극기 |
| Q | 유니 액티브 지원 |
| E | 로비 상호작용·던전 출구 |
| 1 / 2 / 3 | 공개된 증강 카드 선택 |
| ESC | 창 닫기·종료 확인·던전에서 로비 귀환 |

편성과 영구 강화는 로컬에 저장됩니다. 제외된 캐릭터를 선택했던 저장 데이터는 프로이로 전환됩니다.

## Windows 빌드와 검증

Unity 메뉴 **Tools → Liminal → Build Windows Demo**는 로비 시작 씬을 기준으로 `Builds/PirateAllianceDemo/PirateAllianceDemo.exe`를 만듭니다. 전시용 갤러리·개발용 씬은 빌드 시작 목록에서 제외합니다.

`Tools/Demo/Validate.ps1`은 별도 배치 에디터에서 데모 전체 흐름, 로비 UI·강화·게이트, 두 보스 검사를 순서대로 실행합니다. `-Build`를 추가하면 통과 후 Windows 데모를 빌드하고 실행 파일에서도 로비·두 던전의 진입·귀환을 검사합니다. 검사 결과와 검증 범위는 [데모 검증 문서](Documentation/Demo/README.md)를 참고하세요.

기존 콘텐츠와 개발 문서는 `Documentation/`에 보존되어 있습니다. 데모의 선택 가능 범위는 위 목록을 기준으로 합니다.
