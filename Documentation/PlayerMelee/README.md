# 플레이어 기본 공격: 원거리 부적 → 근거리 카타나

참고 영상: 붕괴3rd 야에 사쿠라(역신무녀) 체험. 이아이(발도) 참격, 진홍·벚꽃 분홍·자주 불꽃 참격 궤적, 벚꽃잎, 큰 데미지 숫자를 따랐다. 영상 다운로드는 YouTube 봇 확인에 막혀서, 공개 장면 썸네일만 참고했다.

## 3연격

| 타 | 모션 | 길이 / 판정 | 피해 | 범위 |
| --- | --- | --- | --- | --- |
| 1 | 오른쪽에서 왼쪽으로 수평 베기 | 0.44초 / 0.15초 | 22 | 2.5m · 좌우 70° |
| 2 | 아래에서 위로 올려 베는 역수 베기 | 0.48초 / 0.17초 | 24 | 2.5m · 좌우 70° |
| 3 | 이아이 피니시: 왼쪽 허리에서 크게 뽑아 베고 자세를 유지 | 0.66초 / 0.30초 | 44 | 3.3m · 좌우 115° |

- 조작은 그대로다: 좌클릭 또는 J, 누르고 있으면 연속 공격, 대시로 취소.
- 6m 안의 목표에게는 판정 직전까지 짧게 돌진한다. 그래서 근접 공격도 끊기지 않고 이어진다.
- 평소에는 칼이 왼쪽 허리에 걸려 있다. 공격하면 오른손으로 뽑아 들고(발도), 1.4초 동안 공격이 없으면 다시 허리로 돌아간다.
- 모션은 Humanoid 머슬 커브로 만들었다. 몸통 비틀기, 팔 휘두르기, 런지 다리, 칼을 쥔 손가락이 들어간다. `AstraiaAnimationBuilder`가 `Astraia_Slash_01~03`을 굽는다.
  - 프로젝트를 열면 한 번 자동으로 만들어진다.
  - 다시 굽고 싶으면 **AC Roguelike → Astraia → Rebuild Katana Motions**를 실행한다.
  - 판정은 같은 시각에 맞췄다.

## 타격감

| 상황 | 연출 |
| --- | --- |
| 휘두를 때 | 칼끝 궤적. 초승달 참격(1·2타는 겹 궤적, 3타는 넓은 초승달과 바닥 원형 참격과 벚꽃잎) |
| 적중 | 노란 불꽃 파편, 벚꽃잎, 분홍 고리, 적이 순간 하얗게 번쩍, 데미지 숫자(피니시·마무리 일격은 크고 분홍) |
| 적중 시 시간 | 히트 스톱(1·2타 약 0.06초, 3타 0.11초 슬로우)과 카메라 흔들림 |
| 살아남은 적 | 공격 반대 방향으로 밀려나고(3타는 거의 두 배), 0.22초 움찔한다. 공격 준비 중이면 공격이 조금 늦어진다. |
| 사망 | 공격 방향으로 날아간 뒤 뒤로 넘어져 등으로 착지한다. 한 번 튀며 먼지가 일고, 누운 채 0.9초 뒤 바닥으로 가라앉아 사라진다. |

보스는 경직이 거의 없고 밀림도 작다. 일시정지나 증강 선택처럼 시간이 멈춘 상태에서는 히트 스톱이 시간을 건드리지 않는다.

## 카타나 모델 (Meshy)

Meshy `meshy-7.1`로 만든 벚꽃 코등이 카타나다. 사용량은 30 credits다.

- 처음 나온 결과에는 떨어진 손잡이 한 조각이 공중에 떠 있었다. `Tools/PlayerMelee/clean_katana.py`로 그 조각만 지웠다.
- 정리된 모델은 6,998 → 3,380 삼각형이고, 위치는 `Assets/Characters/Astraia/Resources/AstraiaKatana.glb`다.
- 모델이 없으면 기본 칼날 모양으로 대신 표시한다.

## 코드

| 파일 | 내용 |
| --- | --- |
| `Assets/Gameplay/Scripts/MeleeSlash.cs` | 칼 장착, 돌진, 부채꼴 판정, 피해, 피격 방향, 연출 호출 |
| `Assets/Gameplay/Scripts/HitFeedback.cs` | 히트 스톱, 카메라 흔들림, 참격·불꽃·벚꽃·고리·번쩍임·데미지 숫자·먼지 |
| `PlayerCombat.cs` | 공격 시작·판정·종료 때 근접 공격을 호출한다. 입력·콤보·애니메이션은 그대로다. |
| `TalismanCaster.cs` | 근접 적중을 시전 1회로 센다. 기존 검증과 지원 스킬(1UP 팩맨)이 그대로 동작한다. |
| `TrainingEnemy.cs` | 피격 이벤트, 피격 방향·세기, 사망 연출을 미루는 옵션 |
| `LiminalEnemy.cs` | 넉백, 경직, 사망 비행·착지·소멸 |
| `IsometricFollowCamera.cs` | 카메라 흔들림 |

- 카타나 정리 결과: 재현 가능(같은 해시)

아직 Unity에서 확인하지 않은 것이 있다. 아래 값이 어색하면 `MeleeSlash`의 `swings`와 `AstraiaAnimationBuilder.MakeSlash` 수치로 다듬는다.
