# 복구된 도시의 협회 로비

한 차례 피해를 겪고 다시 운영 중인 한국 도시의 광장이다. 남아 있는 포장과 새로 고친 부분을 함께 보여준다. 보도블록, 점자블록, 석재 경계석, 배수로, 낮은 화단, 수선된 가로시설로 장소의 성격을 잡았다.

## 바닥

- 44 × 36m 광장에 작은 보도블록을 적용했다.
- 새 포장 4구획은 총 322.33m², 광장 면적의 약 20.3%다.
- 보도블록 방향과 색 차이, 절단된 보수 경계, 메운 균열, 배관 공사 이음으로 복구 구간을 구분한다.
- 교체한 맨홀과 배수구, 일부 남은 도색과 다시 칠한 도색을 섞었다.
- 보수 표면은 기존 바닥의 충돌을 그대로 사용한다. 중앙 협회 문양은 표면 위에 유지한다.

## 장식과 주변 건물

- 화단은 오래된 콘크리트와 새 보수재가 섞인다. 일부에는 보강띠와 새 식재를 넣었다.
- 가드레일·울타리·볼라드에 교체된 금속, 볼트, 배관 연결부를 표현했다.
- 유틸리티함과 정리된 보수재는 광장 가장자리에 배치했다.
- 주변 저층 건물은 붉은 벽돌, 오래된 미장, 새 외벽 패치, 교체한 셔터, 옥상 방수와 실외기로 구성했다.
- 외곽 도로에 아스팔트 질감, 재포장 구획, 차선과 횡단보도를 배치했다.

## 시설물 표시

실제 한국어 표지판이나 상호를 사용하지 않는다. 새 시설물은 텍스트와 문자 텍스처 없이 도형으로 표현한다.

| 시설 | 표시 |
|---|---|
| 수리한 자판기 | 컵 기호, 색으로 구분한 캔 |
| 정수기 | 물방울 기호 |
| 주의판 2개 | 삼각형과 번개 |
| 안내 키오스크 | 추상 지도와 점선 경로 |

## 실행과 검증

Unity 6000.3.19f1에서 최종 **114개 검사 통과, 오류 0개**. 결과는 [validation.json](validation.json)에 저장했다.

추가한 바닥·가로시설·기호 시설물·주변 건물은 합계 39,921삼각형, 71개 정적 메시다. 재질별로 묶었고, 새 절차 텍스처의 최대 크기는 1024 × 1024다. 바닥에 새로운 충돌체를 추가하지 않는다.

`Assets/Liminal/Scenes/LiminalRun.unity` 실행 시 시작 로비에서 확인할 수 있다. 인물 13명과 네 활동 거점은 이어서 사용한다.

검사 진입점은 `AcRoguelike.Liminal.Editor.LobbyExpansionValidation.RunBatch`다. 별도 batch editor에서 `-lobbyValidationOutput Documentation/Liminal/LobbyRecovery`를 전달한다. 이동 경로, 강화, 게이트, 인물 동작과 복귀, 새 시설의 문자 컴포넌트 및 생성 메시를 확인한다.
