# 지원 캐릭터 · 유니

컨셉 기획서의 **지원 캐릭터**를 처음 구현했다.

- 지원 캐릭터는 전투에 직접 참여하지 않고 스킬 1종으로 지원한다.
- 지원형 스킬은 시전하는 동안 무적이다.

유니는 토끼 후드를 입은 게이머 소녀다. 스킬 컨셉은 "게임에서 본 오브젝트를 꺼내 도와준다"이다. 그래서 운석, 1UP, 팩맨 모양의 먹보를 모두 복셀로 만들었다.

![HUD](HUD_Yuni.png)

## 스킬: 보너스 스테이지!

| 항목 | 값 |
| --- | --- |
| 키 | **Q** (게임패드 LB) |
| 쿨타임 | 16초 |
| 시전 무적 | 1.3초. 운석이 떨어지는 동안 피해를 받지 않는다. |
| ① 운석 | 18m 안에서 가장 가까운 적에게 복셀 운석 1개가 떨어진다. 0.85초 동안 바닥에 예고 원이 표시되고, 떨어진 뒤 반경 3.4m에 **90 피해**를 준다. 복셀 파편과 충격파가 퍼진다. 주변에 적이 없으면 플레이어 정면 5m에 떨어진다. |
| ② 1UP | 운석이 떨어지면 플레이어 머리 위에 복셀 **1UP**이 **5초** 동안 뜬다. 1UP은 카메라를 향한다. 마지막 1초에는 깜빡인다. |
| ③ 추가 투사체 | 1UP이 떠 있는 동안 부적이 나갈 때마다 복셀 **팩맨**이 함께 발사된다. 팩맨은 같은 적을 쫓아가 **18 피해**를 추가로 준다. 입을 여닫으며 날아가고, 지나간 자리에 펠릿을 남긴다. |

수치는 `LiminalRun` 씬의 `LIMINAL RUN / Seeded Stage Assembly` 오브젝트에 붙은 `SupportCharacterSkill`에서 조정한다.

## 화면 UI (왼쪽 아래)

카드는 남색 패널과 금색 강조색을 사용한다. 해상도 1280×720 기준 좌표이며, 하단 조작 안내 바로 위에 놓인다. 2026-10-16 사용자 제공 일러스트로 교체하고 꼬끼오와 같은 통신 모니터 효과를 적용했다.

- **통신 모니터**
  - 어두운 베젤 안에 푸른 LCD 색감, 천천히 흐르는 스캔라인, 초록색 통신 램프를 표시한다.
  - 새 그림의 얼굴과 휴대용 게임기가 보이도록 위쪽 55%를 중심으로 표시하며 원본 비율을 유지한다.
  - 원본은 `Assets/Liminal/Resources/SupportSkill/support_yuni_portrait.png`. 사용자 제공 파일을 그대로 사용하고 기존 GUID를 유지하므로 편성 창에도 같은 그림이 반영된다.
  - 하단 이름표: `SUPPORT · 유니`
  - 스킬을 쓰면 일러스트 창이 한 번 튄다.
- **스킬 슬롯**
  - 8비트 팩맨 아이콘과 `1UP` 표기가 있다.
  - 쿨타임은 원형으로 줄어드는 음영과 남은 초로 보여 준다.
  - 형광등색 **Q** 키 배지가 붙어 있다.
  - 준비되면 테두리가 깜빡인다.
- **상태**
  - `준비 완료`, `재충전`, `추가 투사체` 중 하나를 표시한다.
  - 1UP 남은 시간은 막대와 초로 보여 준다.

하단 조작 안내에도 `Q 지원 스킬`을 추가했다.

## 오브젝트 (Meshy)

Meshy `meshy-7.1` text-to-3D로 세 오브젝트를 생성했다. 사용량은 **90 credits**다. 도구는 `Tools/SupportSkill/meshy_support_skill.py`이고, 키는 `MESHY_API_KEY` 환경 변수로만 읽는다.

| 오브젝트 | Meshy 원본 | 복셀 결과 |
| --- | --- | --- |
| 운석 | ![](Meshy_voxel_meteor.png) | ![](voxel_meteor_voxels.png) 18칸, 2,944 삼각형 |
| 1UP | ![](Meshy_voxel_1up.png) | ![](voxel_1up_voxels.png) 34칸, 6,044 삼각형 |
| 팩맨 | ![](Meshy_voxel_chomper.png) | ![](voxel_chomper_voxels.png) 16칸, 3,288 삼각형 |

Meshy는 모양과 색은 잘 잡았지만, 표면이 매끈하거나 바위 조각이라 복셀처럼 보이지 않았다. 그래서 `Tools/SupportSkill/voxelize.py`로 진짜 복셀로 바꿨다.

1. Meshy 메시와 텍스처를 큐브 격자로 샘플링한다.
2. 색을 작은 픽셀아트 팔레트로 맞춘다.
3. 밖으로 드러난 면만 GLB로 쓴다. 팔레트는 nearest 필터이고, 발광 팔레트를 따로 둔다.

오브젝트별로 추가 보정을 했다.

- 운석: 빛나는 용암 균열을 넣었다.
- 1UP: 하트 색을 분홍으로 되살렸다.

![objects](Skill_objects.png)

파일 위치:

- Meshy 원본과 생성 기록: `Assets/Liminal/Art/SupportSkill/<key>/`
- 게임에서 쓰는 복셀 모델과 일러스트: `Assets/Liminal/Resources/SupportSkill/`. 여기 모델이 없으면 코드가 같은 모양의 절차 복셀로 대신 만든다.

## 테스트

2026-10-16 이미지·모니터 변경: Unity 6000.3.19f1에서 컴파일 후 실제 `LiminalRun`을 실행했다. HUD와 [지원 캐릭터 편성 창](../Loadout/loadout_window_yuni.png)을 캡처해 새 그림과 모니터 효과를 확인했고, 기존 편성·지원 캐릭터 검사 39개가 통과했다. [검사 기록](yuni-monitor-validation.json).

1. `Assets/Liminal/Scenes/LiminalRun.unity`를 열고 Play를 누른다.
2. 전투방에서 **Q**를 누른다. 운석이 떨어지고 1UP이 뜬다.
3. 5초 동안 좌클릭으로 공격하면 팩맨이 함께 나간다.

- 쿨타임은 탐색 중에만 흐르고, 일시정지·증강 선택 중에는 멈춘다.
- 자동 테스트에서는 `SupportCharacterSkill.TryActivate()`를 호출하면 된다. `Activations`와 `ChompersFired`로 결과를 확인한다.

초기 스킬 구현은 Unity 에디터 없이 했으며, 당시 확인 범위는 다음과 같다.

- C# 컴파일: Unity 6000.3.19f1 참조 어셈블리로 통과
- GLB 읽기와 렌더: three.js로 확인
- UI 배치: 같은 좌표로 그린 목업으로 확인

실제 Play 화면의 느낌(발광 세기, 크기)은 Unity에서 한 번 보고 `SupportCharacterSkill` 값으로 다듬으면 된다.
