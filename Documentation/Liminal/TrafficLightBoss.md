# 신호등 보스

Meshy로 만든 낡은 신호등을 몸체로 쓰고, 팔·다리를 전선 다발로 구성한 대형 보스다. 자판기 몬스터와 같은 방식(Generic 리그 + 편집 가능한 AnimationClip + `TrainingEnemy` 체력)으로 만들어 기존 플레이어 전투·회피를 그대로 쓴다.

## 바로 사용하기

- 프리팹: `Assets/Liminal/Prefabs/Enemies/TrafficLightBoss.prefab`
- 자동차 프리팹 3종: 같은 폴더의 `TrafficLightCar_rusted_sedan / yellow_taxi / delivery_van.prefab`
- 플레이 테스트 장면: `Assets/Liminal/Scenes/TrafficLightBossShowcase.unity` (28×36m 경기장, 보스 휴면 상태로 시작)
- 재생성: Unity 메뉴 `AC Roguelike > Liminal > Traffic Light Boss > Build Boss`, 장면은 `Create Playable Showcase`
- 스테이지 연동: 방 프리팹 안에 보스 프리팹을 두면 `LiminalRunDirector`가 그 방 입장 시 활성화하고, 일반 보스(`관리자`) 생성은 건너뛴다. 체력바도 HUD에 표시된다. 기존 4스테이지 보스 방은 **교체하지 않았다.**

## 크기

| 항목 | 값 |
| --- | --- |
| 기립 전체 높이 | **12.0m** (자판기 몬스터 3.08m의 약 3.9배, 자판기 몸체 1.9m의 약 6.3배) |
| 휴면 높이 | 7.2m (평범한 대형 신호등) |
| 몸통(신호등 본체) | 높이 8.0m 중 폴 조각 0.8m, 골반 높이 4.8m |
| 팔 | 어깨~손목 9.0m + 손 끝 전선 1.8m |
| 다리 | 엉덩이~발목 4.0m + 발 끝 전선 0.9m |

자판기 몬스터의 6배(18.5m)는 플레이 카메라(시야각 36°, 거리 15.5m, 최대 24m, 55° 내려다보기) 기준으로 머리가 화면 밖으로 나가 패턴을 읽을 수 없어 12.0m로 조정했다(0.5m 단위).

보스가 깨어난 동안은 카메라를 거리 24m, 62°로 내려다보게 하고, 시선을 플레이어와 보스의 중간 쪽으로(최대 9m) 옮기면서 최대 6.5m 올린다. 사용 필드는 `IsometricFollowCamera.focusOffset`이며 기본값이 0이라 다른 장면에는 영향이 없다. 보스가 쓰러지면 원래 각도로 돌아간다. 값은 `TrafficLightBoss`의 `cameraDistance`, `cameraPitch`, `cameraFocusLift`로 조정한다.

## 신호등 램프

램프는 항상 켜져 있고 자주 바뀐다. 순서는 **빨강 → 초록 → 노랑** 반복이다.

| 상태 | 램프 |
| --- | --- |
| 휴면 | 모두 꺼짐 |
| 각성 | 무작위로 깜빡임 |
| 대기·이동 | 빨강 0.9초 → 초록 0.9초 → 노랑 0.4초 반복 |
| 패턴 1 | 충전 중 빨강 고정, 판정 순간 초록 |
| 패턴 2 | 던지기 전 노랑, 발사 후 0.6초 초록, 이후 빨강 |

켜진 램프 색으로 주변 조명도 바뀐다. 램프는 본체 텍스처에 구워 넣지 않고 별도 발광 렌즈로 만들어 색을 전환한다.

## 패턴 1: 빨간 빛 바닥

1. 0.45초에 방 전체 바닥이 붉게 차오르고, 파란 원이 커지며 나타난다(0.7초).
2. 2.6초에 원이 **초록**으로 바뀌며 판정한다. 플레이어 **발 위치**가 어떤 초록 원에도 들어 있지 않으면 피해 28(2페이즈 34)을 준다.
3. 판정은 0.9초 동안 0.45초 간격으로 이어진다. 플레이어 무적 시간(0.8초)과 대시 무적이 그대로 적용된다.

- 원 반지름 3.2m, 3개(2페이즈: 2.7m, 2개). 원 하나는 항상 플레이어 주변 3.5~7.5m에 생성되어 예고 시간 안에 도달할 수 있다.
- 바닥 크기는 방 `localBounds`를 따른다(방이 없으면 28×36m).

## 패턴 2: 자동차 던지기

1. 보스가 바닥에서 자동차를 집어 머리 위로 들어 올린다(0.45초 생성, 1.95초 발사).
2. 1.3초에 조준이 고정되고 그때부터 바닥에 폭 2.6m의 붉은 예고 띠가 표시된다. 발사 후에는 추적하지 않는다.
3. 자동차는 고정된 방향의 **일직선**으로 17m/s로 날아가 3.2m 안에 바닥 높이로 내려오고, 이후 바닥을 미끄러진다. 방 벽을 넘으면 사라진다.
4. 피해 26(2페이즈 32). 자동차 1대당 한 번만 맞는다.

자동차 모델은 녹슨 세단(4.6m), 노란 택시(4.6m), 배달 밴(5.6m) 3종이다. 섞은 순서로 한 번씩 모두 나온 뒤 다시 섞으며, 같은 모델이 연달아 나오지 않는다. 2페이즈(체력 50% 이하)에는 자동차를 연속으로 두 번 던질 수 있다.

## 동작 요약

| 항목 | 값 |
| --- | --- |
| 체력 | 1200 + 스테이지×50 |
| 감지 | 26m |
| 각성 | 3.6초(전선 팔 전개 → 다리가 본체를 들어 올림) |
| 이동 | 2.2m/s, 플레이어와 9.5m 거리 유지 |
| 공격 | 13m 안에서만 시작, 간격 1.5초(2페이즈 1.05초), 패턴 1·2 교대 |

## 리깅과 애니메이션

- 팔다리는 전선 12가닥을 꼬아 만든 스킨 메시다(검정 피복 + 빨강·노랑·초록·파랑·흰색 가닥). 끝은 노출된 구리 가닥 또는 커넥터 플러그이며 코드로 생성한다(`TrafficLightBossBuilder`).
- 관절: 몸통 1, 팔 각 3, 다리 각 3 = 13개. 팔다리는 2관절 IK로 자세를 만들고 60fps로 샘플링해 편집 가능한 클립 7개(Dormant, Awakening, Idle, Walk, FieldCast, CarThrow, Recovery)로 저장한다.
- `CarThrow` 클립에 AnimationEvent `SpawnCar`(0.45초), `ReleaseCar`(1.95초)가 들어 있다. 이벤트가 누락되어도 `LateUpdate`가 시간 기준으로 보완한다.

## 생성과 재현

1. `Tools/TrafficLightBoss/meshy_assets.py run`: 본체(image-to-3D, 제공된 신호등 사진에서 켜진 렌즈만 어둡게 처리한 `Source/reference_unlit.png` 사용)와 자동차 3종(text-to-3D)을 Meshy로 생성. 인증키는 `MESHY_API_KEY` 환경변수로만 읽는다.
2. Unity `TrafficLightBossBuilder.Build()`: 자동차 프리팹, 전선 메시, 재질, 효과음, 클립, 보스 프리팹 생성.

Meshy 생성 기록과 프롬프트는 `Assets/Liminal/Art/TrafficLightBoss/Meshy/*/provenance.json`에 있다.

| 모델 | 방식 | 게임 삼각형 |
| --- | --- | ---: |
| 신호등 본체 | image-to-3D, meshy-7.1 | 29,128 |
| 녹슨 세단 | text-to-3D | 6,765 |
| 노란 택시 | text-to-3D | 6,815 |
| 배달 밴 | text-to-3D | 7,601 |

전선 팔다리 4개는 코드로 생성한 메시다. Meshy 사용량은 잔액 기준 **총 170 credits**(3,413 → 3,243)이며, 서버 오류로 실패한 세단 1차 작업이 포함되어 있다.

## 검증

메뉴 `AC Roguelike > Liminal > Traffic Light Boss > Run Play Validation`은 쇼케이스를 실제로 재생하고 플레이어 이동·체력 API로 36개 항목을 확인한다. 결과는 `Documentation/Liminal/Concepts/TrafficLightBoss/validation.json`에 저장되고, 화면 캡처는 같은 폴더의 `Review/`에 저장된다.

- 휴면·각성·12m 기립, 램프 빨강→초록→노랑 순서와 1초 미만 간격
- 패턴 1: 원 개수·반지름·경기장 안 배치, 가까운 원 보장, 원 경계에서 발 기준 판정, 원 밖 피해 28, 원 안 무피해
- 패턴 2: 노랑 예고, 일직선 궤적(오차 0.000m), 바닥 하강, 선 위 피격 26, 조준 고정 후 옆으로 피하면 무피해, 벽에서 제거, 3회 투척에 3종 모두 등장
- 2페이즈 원 축소, 사망 시 장판·램프·자동차 정리

마지막 실행은 4회 연속 통과했다. 검증 중에는 플레이어의 자동 공격을 꺼서 보스 체력이 판정 순서를 방해하지 않게 한다.
