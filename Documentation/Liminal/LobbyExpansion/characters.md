# 로비 인물 확장

기존 협회 직원의 애니메이션풍 표현을 이어간다. 직업과 경력이 먼저 보이도록 색과 체형을 나눴다. 기존 게임 캐릭터를 복제하지 않은 신규 인물이다.

| 인물 | 외형 기준 | 로비에서 보여줄 행동 |
|---|---|---|
| 현장 의료요원 | 민트·아이보리. 갈색 단발. 작은 구급 가방. | 상담, 경청, 의약품 확인, 인사 |
| 게이트 정비사 | 주황 작업조끼. 넓은 어깨. 고글과 공구 주머니. | 장비 확인, 연락, 설명, 인사 |
| 신입 헌터 | 청록 재킷. 큰 배낭. 가는 체형. | 준비운동, 숨 고르기, 활기찬 인사, 대화 |
| 베테랑 헌터 | 와인색 코트. 은색 짧은 머리. 단단한 체형. | 조언, 음료 마시기, 주변 확인, 인사 |

## 리소스 규칙

- 모델은 한 명당 20,000 삼각형을 목표로 생성한다.
- 알베도는 2K. 작은 소품과 의상 장식은 큰 형태를 가리지 않게 한다.
- 손을 비운 A포즈를 기준으로 리깅한다. 휴대전화와 컵은 행동에 맞춰 손 본에 붙인다.
- 각 인물은 대기·보행·대화·인사와 역할 행동 2개를 가진다.
- 보행의 실제 이동은 로비 동선 코드가 담당한다. 클립의 루트 이동을 그대로 적용하지 않는다.
- 대화와 역할 행동은 번갈아 재생한다. 모든 사람이 같은 순간에 같은 동작을 시작하지 않게 한다.

## 제작 기록

1. 기존 `Tools/LiminalLobby/Reference/official.png`를 화풍 참고로 사용한다.
2. Meshy Image to Image의 `gpt-image-2`로 새 인물의 전신 콘셉트를 만든다.
3. 포즈·복장·실루엣을 확인한 뒤 Meshy 7.1 Image to 3D로 제작한다.
4. Meshy 리깅과 라이브러리 모션을 적용한다.
5. 원본 과금 작업 ID와 실제 폴리곤 수는 각 인물 폴더의 `provenance.json`에 남긴다.

실제 사용량은 총 260 credits다. 4명 × (콘셉트 12 + 모델 30 + 리그 5 + 애니메이션 6개 × 3). 생성 작업 36개가 완료됐다. 실패한 작업을 자동으로 재발행하지 않는다. 키와 서명된 다운로드 URL은 커밋하지 않는다.

재실행: `python Tools/LobbyExpansion/meshy_lobby_expansion.py concept` 후 콘셉트를 확인하고 `python Tools/LobbyExpansion/meshy_lobby_expansion.py build`. 기존 작업 ID가 있으면 이어서 받는다.

## 모션 목록

| 인물 | 라벨 | Meshy action ID |
|---|---|---|
| 의료요원 | idle / walk / talk / greet / inspect / listen | 247 / 1 / 313 / 290 / 281 / 47 |
| 정비사 | idle / walk / talk / greet / phone / inspect | 249 / 30 / 314 / 290 / 312 / 276 |
| 신입 | idle / walk / talk / greet / warmup / breath | 244 / 30 / 56 / 28 / 326 / 31 |
| 베테랑 | idle / walk / talk / greet / drink / look | 251 / 106 / 309 / 290 / 342 / 338 |

`inspect`는 정비·치료 시뮬레이션 전체가 아닌 물건을 집어 확인하는 동작이다. 정비사 모션을 도구로 수리하는 동작으로 오해하지 않도록 소품과 위치를 맞춘다. `warmup`은 점핑잭이다.

`phone`과 `drink`는 모두 왼손을 사용한다. 생성된 GLB의 손·머리 본 위치를 여러 시간대에서 확인했다. 소품은 왼손에 붙인다.

수치는 전달받은 원본 GLB 기준이다. 인물별 본체 FBX 1개와 모션 FBX 6개를 전달했다. Unity 임포트·리타기팅 결과는 실제 로비 검증에서 별도로 확인한다.
