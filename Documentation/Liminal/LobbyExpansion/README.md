# 협회 로비 인물과 생활 확장

기존 협회 직원·경비원에 의료요원, 정비사, 신입 헌터, 베테랑 헌터를 더했다. 로비 NPC는 8명에서 13명으로 늘었다. 신입 모델 하나는 진료 상담을 받는 방문자로도 사용한다.

## 공간과 행동

| 공간 | 인물 | 행동과 소품 |
|---|---|---|
| 왼쪽 의료 구역 | 의료요원 + 상담 방문자 | 상담·경청·물품 확인. 구급함, 붕대, 소독제, 기록지 |
| 왼쪽 입구 정비 구역 | 게이트 정비사 | 장비 확인·전화·설명. 정비용 검, 공구, 충전기, 작업등 |
| 오른쪽 입구 휴식 구역 | 신입 헌터 | 점핑잭·숨 고르기·대화. 컵, 안내지, 의자, 배낭, 작은 화분 |
| 오른쪽 게이트 앞 브리핑 구역 | 베테랑 헌터 | 주변 확인·커피·조언. 입체 경로지도와 기록지 |

의료는 청록, 정비는 주황, 휴식은 와인색으로 표시한다. 협회 공간의 남색·백색·금색은 이어간다. 중앙 문양, 시작 지점, 강화 담당자와 게이트까지 이어지는 통로는 비워 둔다. 가구 간격은 실제 인물과 기존 벤치·가로등 위치에 맞췄다.

NPC마다 활동 순서와 시작 시점을 다르게 둔다. 상담하는 두 인물은 번갈아 이야기한다. 플레이어가 가까워지면 인사하고 바라본다. 순찰 직원은 사람이나 가구가 길을 막으면 기다린다. 대화 중인 담당자는 대화 동작을 우선한다.

전화기와 커피컵은 실제 왼손을 따라가며 해당 행동 중에만 보인다. 역할 동작은 처음부터 시작하고 부드럽게 이어진다. 점핑잭은 두 발이 공중에 뜨는 원래 동작을 유지한다. 일시정지와 던전 입장 시에는 움직임이 멈추고 로비로 돌아오면 재개한다.

## 리소스

Meshy로 새 인물 4종과 인물별 Humanoid 모션 6개, 총 24개 클립을 제작했다. 각 모델은 약 2.1만 삼각형, 2K 알베도 1장, 몸체 머티리얼 1개다. 생성 콘셉트, 사용한 모션, 실제 사용량과 제작 경로는 [인물 제작 기록](characters.md)에 정리했다.

작업대와 의료·휴식 소품은 코드에서 생성하고, 공간별로 같은 재질의 메시를 합친다. 매 프레임 움직이는 장식은 상태 표시등 4개다. NPC와 소품은 로비 인스턴스를 재사용한다.

## 확인 방법

Unity 6000.3.19f1에서 최종 실행 검사 96개 통과, 오류 0개. 새 인물 4종의 24개 모션은 실제 본 움직임을 확인했다. 자연스러운 활동 순환, 순찰, 인사, 소품 표시, 일시정지, 강화 구매, 게이트 진입과 복귀까지 검증했다. [실행 결과](validation.json)와 [임포트 결과](import.json)를 함께 저장했다.

- `Assets/Liminal/Scenes/LiminalRun.unity`를 실행하면 시작 로비에 바로 나타난다.
- 임포트 재검사: `AC Roguelike > Liminal > Import Additional Lobby Characters`.
- 로비 통합 검사: 별도 Unity batch editor에서 `AcRoguelike.Liminal.Editor.LobbyExpansionValidation.RunBatch` 실행. 이 검사는 Play Mode로 전환하므로 `-quit` 옵션을 붙이지 않는다.
- 임포트와 실행 결과는 `Library/LobbyExpansionValidation/`에 기록한다. 검사에서 사용한 강화·방문 기록은 종료 시 원래 값으로 복구한다.
