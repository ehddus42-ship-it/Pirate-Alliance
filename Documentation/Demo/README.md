# 데모 통합과 검증

대상: 프로이 / 유니·꼬끼오 / 리미널 스페이스·게임 테마 / 로비 편성·영구 강화 / 공통 전투 시스템.

main은 Unity에서 계속 편집할 수 있는 원본 프로젝트입니다. 스크립트·씬·프리팹·에셋·설정과 검증 도구를 관리하며, `Builds/`의 실행 파일과 게임 데이터는 Git에서 제외합니다.

아스트라이아와 미완성 남궁루나는 플레이 선택에서 제외합니다. 로비 캐릭터 선택 시스템은 유지하며, 프로이가 기본 캐릭터입니다. 기존 저장 데이터가 제외된 캐릭터를 가리켜도 프로이로 전환합니다.

## 검사 범위

- `LoadoutValidation.RunBatch`: 실제 로비 편성 UI와 저장, 프로이 평시복·전투복 전환, 실제 3타 콤보와 유니 추가 투사체, 궁극기, 꼬끼오 드롭·3% 회복, 잡기·투척·화염공, 전용 증강, 두 미션의 방 잠금·해제·증강·승리·보상·귀환, 영구 강화의 다음 런 적용, 패배·동일 미션 재도전.
- `GateMissionValidation.Run`: 두 미션의 경로·발견 처리·환경 복원·재도전, 강화창 반복 구매, 한글 글리프, 1280×720·1024×768에서 UI 누락·잘림 검사.
- `GameTetrominoBossValidation.RunBatch`: 게임 보스의 공격·피해·반사·돌진·실제 미션 진입·처치·재도전·귀환.
- `TrafficLightBossPlayValidation.Run`: 리미널 보스의 신호·광역 판정·투척·피격·회피·중단 처리.
- `DemoBuild.BuildWindows`: 실제 Windows 실행 파일 생성과 빌드 결과 기록.
- 빌드된 실행 파일의 `-demoSmokeTest`: 로비·프로이 평시복, 한글 UI, 두 던전의 실제 리소스 로드·전투 시작·귀환을 에디터 없이 검사합니다. 정상 실행에서는 검사 기능이 생성되지 않습니다. 편성과 발견 상태를 복원하고 `smoke-report.json` 및 실제 화면 3장을 빌드 폴더에 남깁니다.

전체 진행 검사에서는 방 사이를 시험용 위치 이동으로 연결하고, 진행·보상 검증을 위해 적을 테스트 피해로 정리합니다. 프로이의 콤보·기본 스킬·궁극기·지원 효과는 별도 실제 대상에 실행합니다. 자동 검사 통과는 사람의 연속 수동 플레이, 난이도 평가나 기기별 성능 측정을 뜻하지 않습니다.

전체 흐름 검사는 변경한 편성과 강화·재화·발견 상태를 종료 시 복원합니다. 검사 로그는 `Logs/demo-*.log`, 결과와 화면은 `Validation/` 및 기존 개별 검증 폴더에 저장합니다.

검증 스크립트는 대용량 리소스가 LFS 참조 파일로 남아 있으면 실행을 중단합니다. 새 작업 공간에서 Unity 배치 실행에 필요한 로컬 Search 인덱스 설정도 준비합니다. 게임 보스 검사는 저장된 에셋을 그대로 검사하며 에셋을 재생성하지 않습니다.

## 통합한 주요 수정

- 프로이에게 잡히거나 던져진 몬스터의 AI 정지, 프로이가 붙잡힌 경우 스킬 중단과 대상 해제.
- 회피 중 공격 범위 가까이 비껴간 공격도 저스트 회피로 판정.
- 신호등 보스 광역 공격의 판정 2.5초 전 초록 신호 표시.
- 로비 복장이 캐릭터 목록의 순서에 의존하던 부분을 실제 모델 기준으로 수정.
- 데모 선택 목록과 빌드 시작 씬을 완성 콘텐츠 범위로 제한.
