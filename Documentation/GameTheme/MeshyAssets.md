# Game 테마 환경 소품

복셀 몬스터와 게임판 구조물을 연결하는 레트로 하드웨어 소품 묶음이다. 실재 브랜드의 로고나 캐릭터를 복제하지 않고, 화면·조작부·카트리지·버튼처럼 게임 기기를 알아보게 하는 형태를 사용한다.

## 배치 기준

- 기본 팔레트는 짙은 네이비와 아이보리. 청록·호박색·라즈베리색을 화면과 조작부에 제한적으로 사용한다.
- 아케이드와 핀볼은 벽 쪽 구경거리, 거대 휴대게임기와 카트리지 아치는 먼 거리에서도 보이는 상징물로 사용한다.
- 높은 소품은 방의 뒤쪽 또는 가장자리에 배치한다. 낮은 컨트롤러 벤치는 중앙 구간에 사용할 수 있지만 이동 폭을 확보한다.
- 화면과 조작부가 게임 카메라를 향하도록 회전한다. 소품의 뒷면만 보이는 반복 배치를 피한다.
- `target_size_m`은 제작 목표 외곽 크기이며 강제 비균등 스케일이 아니다. 실제 메시의 비율을 유지한 채 목표 높이나 폭에 맞추고, 발판이 지면에 닿게 바닥 높이를 보정한다.
- 카트리지 아치 중앙은 통과 가능한 빈 공간이다. 아치 전체를 막는 단일 박스 충돌체를 사용하지 않는다.
- 모든 GLB는 자체 메시·UV·PBR 재질을 포함한다. 동일 종류를 반복 배치할 때 원본 메시와 재질을 공유하고 텍스처를 복제하지 않는다.

## 제작과 검수

Meshy 7.1의 텍스트→메시→PBR 질감 과정을 사용했다. API 키는 `MESHY_API_KEY` 환경 변수로만 읽으며 저장하지 않는다. 요청 내용·작업 ID·실제 삼각형 수·Unity 좌표의 로컬 경계는 각 모델의 `provenance.json`에 기록한다. 전체 목록과 크레딧 내역은 `meshy-assets.json`을 참조한다.

소품별 목표는 7,000~12,000 삼각형이다. 현재 아포칼립스/동굴 확장 소품의 약 13,000~29,000 삼각형보다 낮은 목표로 설정했다. 단순한 외곽선에 필요한 모양을 남기고, 작은 패널·틈새·재질 변화는 노멀맵에 맡긴다. 실제 장면의 부하는 인스턴스 수·그림자·동시 표시 범위를 포함해 따로 확인한다.

반복 소품은 텍스처를 1K로 제한하고, 휴대게임기·아치·레이싱 기기 상징물은 2K를 유지한다. 축소한 노멀맵 벡터는 다시 정규화한다. 원본은 무시된 로컬 캐시에 보관하므로 화질을 다시 조정할 수 있다.

형상 미리보기와 질감 미리보기를 직접 검수했다. 최초 레이싱 기기는 도로용 자동차처럼 읽혀 폐기하고, 고정된 화면 캐비닛과 좌석이 있는 오락실 기기로 다시 생성했다. 간판에 생긴 원치 않는 글자도 질감 재생성으로 추상 패널로 바꿨다. 통과 여부와 카메라 가림은 Unity 방 캡처에서 검수한다.

최종 8종 합계는 **57,366 삼각형 / 26.92MB**다. 각 GLB는 메시 1개·재질 1개·노멀맵 1개이며 5종은 1K, 상징물 3종은 2K다. 최초 생성과 재시도를 합쳐 **280크레딧**을 사용했다. 화면은 PBR 베이스컬러에 포함되며 별도 발광맵은 없으므로, 어두운 방에서는 화면 쪽 보조광이나 별도 발광 장식을 사용한다.

## 재생성

저장된 작업 ID를 재사용하므로 중단 후 같은 명령을 실행하면 이어서 진행한다. 모호한 요청 실패를 자동 재전송하지 않아 중복 결제를 막는다. 기본 전체 상한은 360크레딧이다.

```text
python Tools/GameTheme/meshy_assets.py plan
python Tools/GameTheme/meshy_assets.py run --dry-run
python Tools/GameTheme/meshy_assets.py run --workers 4 --budget 360
python Tools/GameTheme/optimize_textures.py
python Tools/GameTheme/meshy_assets.py inspect
```

API 규격: [Meshy Text to 3D](https://docs.meshy.ai/en/api/text-to-3d)
