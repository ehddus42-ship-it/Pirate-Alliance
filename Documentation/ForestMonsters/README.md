# 판타지 숲 몬스터

로비의 `G-02 / forest_survey`로 들어가면 `concept_forest` 전투방에서 숲 전용 몬스터가 등장한다. 전투방마다 세 마리씩 등장하며, 세 전투방을 진행하면 네 종류를 모두 만난다. 소환된 묘목은 방 클리어 수에 포함하지 않는다.

| 몬스터 | 동작 / 공격 | 회피와 대응 |
| --- | --- | --- |
| 달빛 지렁이 | 1.05초 원형 예고 → 흙과 뿌리가 붙은 덩어리를 튀기며 솟음 → 접근 → 0.8초 직선 예고 → 몸을 낮추고 꾸물거리며 돌진 | 지하에서는 타깃·피해 판정 없음. 예고 방향은 고정. 지상 회복 중 공격 가능 |
| 이끼 개구리 | 웅크림 → 도약 → 착지. 0.8초 직선 예고 뒤 혀를 뻗어 적중한 플레이어를 앞으로 끌어당김 | 도착 또는 최대 0.85초 뒤 해제. 벽·죽음·비활성 시 즉시 해제. 대시 회피 가능. 해제 뒤 2.2초 재포획 면역 |
| 달가루 나비 | Meshy 날개를 실제로 펄럭이며 부유. 1.05초 원형 예고 뒤 반경 4.2m 가루 공격. 다음 공격은 0.9초 예고 뒤 잎을 휘감은 회오리 투사체 | 가루 밖으로 이동하거나 예고 방향 옆으로 회피. 회오리는 벽에서 사라짐 |
| 달빛 고목 | 묘목을 포물선으로 투척. 다음 공격은 1.2초 예고 뒤 아치형 뿌리가 땅을 드나들며 전진 | 묘목을 먼저 제거하거나 뿌리 진행선에서 벗어남 |
| 성난 묘목 | 착지 후 2.6초 대기 → 플레이어 추격 → 0.8초 범위 예고 → 반경 2.55m 폭발 | 착지부터 무기로 파괴 가능. 파괴하면 폭발 취소. 고목이 죽거나 방이 정리되면 함께 제거 |

## 리소스와 연출

- Meshy AI로 지렁이·개구리·나비·고목·묘목·흙덩이 6종 생성.
- 몸체 5종은 2K PBR, 흙덩이는 1K PBR. 기본 모델 총 64,755 triangles, GLB 약 38MB.
- 지렁이 몸통, 개구리 다리·몸통, 나비 날개, 나무 가지는 원본 메쉬를 복제해 변형한다. 노멀·탄젠트도 함께 보정한다.
- 혀는 굵기가 변하는 8각 튜브 메쉬다. 연장·굽힘·회수 동작에 맞춰 실시간으로 변형한다.
- 지렁이 분출은 Meshy 흙덩이 9개, 작은 파편, 흙먼지, 파인 지면으로 구성한다.
- 회오리는 반대 방향으로 도는 반투명 리본 3개, 가는 바람선 6개, 잎과 입자로 구성한다.
- 뿌리는 굵은 아치 4개가 연속으로 드러났다 잠기며 전진한다. 뿌리 전체가 한 공격당 한 번만 피해를 준다.
- 리소스 출처·생성 설정·후처리 내용은 `meshy-assets.md`와 `meshy-assets.json`에 기록했다.

## 재생성과 검증

Unity 6000.3.19f1 기준. 다른 에디터가 같은 프로젝트를 열고 있지 않을 때 실행한다.

에디터 메뉴 `AC Roguelike > Forest > Build Forest Monsters`로 Meshy GLB에서 읽기 가능한 변형 메쉬와 Resources 프리팹을 다시 만든다. 숲 미션의 기믹 설명도 함께 갱신한다.

배치 통합 검증 진입점은 `AcRoguelike.Forest.Editor.ForestMonsterValidation.RunBatch`다. `-batchmode -projectPath <project> -executeMethod <entry> -logFile <log>`로 실행한다. Play Mode 검사 종료 후 스스로 종료하므로 `-quit`를 붙이지 않는다.

검증은 실제 로비 진입·숲 세 방의 등록과 문 잠금/해제·출구·재시도·귀환·다른 테마 분리를 확인한다. 별도 임시 공간에서 혀의 충돌/해제/대시, 지렁이 예고/돌진, 회오리와 뿌리의 얇은 벽 충돌, 묘목의 지연/폭발/파괴/장애물 착지, 일시정지와 사망 시 정리를 검사한다. 저장된 진행도는 검사 전 백업하고 종료 때 복원하며, 열린 씬은 저장하지 않는다.

실행 결과는 `Library/ForestMonsterValidation/validation.json`과 PNG 캡처로 남는다. 검수용 최종 결과는 이 문서 옆 `Validation` 폴더에 보관한다. `forest-*`는 실제 숲 씬, `canopy_*`·혀/분출 이미지는 행동 검증용 임시 공간, `meshy-assets-final-*`는 모델 후처리 검수 이미지다.

최종 검증: 2026-10-05, Unity 6000.3.19f1에서 58개 검사 통과, 실행 오류 0개. 낮은 장애물 착지 보정과 최종 파티클 셰이더를 포함한 실행 결과다.
